# Blocked Roadmap Items

These items require external credentials, a licensed source asset, a machine-specific decision, or an external service. They are intentionally not part of the active roadmap.

- PSGallery publication of `Install-Script ThankYouJeffrey`: the publishing workflow and local package metadata are prepared, but a PSGallery API key is required to publish.
- Winget / Chocolatey marketplace distribution: the Chocolatey package scaffold is prepared, but Winget requires a stable release asset and both stores require external submission/review.
- GitHub Release with an Authenticode-signed script: signing requires an Authenticode certificate and private key that are not available in the workspace.
- ASCII-art portrait of Jeffrey: requires a licensed source photograph and a human-approved portrait treatment.
- Archive.org anniversary snapshot: requires an external archive service submission and an owner-selected anniversary schedule.
- Birthday/retirement-anniversary scheduled task: requires a machine-specific schedule and permission to create an operating-system task.
- PowerShell Notes of the Week / community RSS integration: requires an external feed contract and an owner-approved refresh policy.
